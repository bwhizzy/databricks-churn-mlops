# Databricks Customer Churn MLOps

An end-to-end MLOps portfolio project demonstrating model training, MLflow experiment tracking, Unity Catalog model registration, CI/CD, Docker deployment, API testing, monitoring, and rollback.

## Architecture

- Databricks: model development and training
- MLflow: experiment tracking and model packaging
- Unity Catalog: governed model registration and versioning
- GitHub Actions: automated tests and release checks
- Docker and FastAPI: production-style model serving

## Project status

Phase 1: repository setup
Phase 2: model training and evaluation
Phase 3: MLflow tracking and Unity Catalog registration
Phase 4: automated Databricks Jobs
Phase 5: CI/CD
Phase 6: containerized API deployment
Phase 7: monitoring and rollback
